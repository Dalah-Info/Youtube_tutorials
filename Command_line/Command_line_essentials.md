
## **أهم الأوامر التي يجب على كل مبتدئ في تعلم واجهة الأوامر أن يعرفها*

---

### 1. `touch`
**وظيفة الأمر:** إنشاء ملف فارغ.
```bash
# إنشاء ملف جديد فارغ باسم file.txt
touch file.txt

```

 
### 2. `man touch`
**وظيفة الأمر:** عرض دليل استخدام الأمر

 ```bash
# فتح دليل الاستخدام
man touch

 ```


### 2. `ls`
**وظيفة الأمر:** عرض محتويات المجلد الحالي

 ```bash
# عرض الملفات والمجلدات العادية
ls
# عرض الملفات والمجلدات بما فيها الملفات المخفية
ls -a
# عرض الملفات بتنسيق تفصيلي
ls -l
# عرض الملفات بشكل تفصيلي مع الملفات المخفية
ls -la
# عرض الملفات بترتيب عكسي
ls -r

```

### 2. `mkdir`
**وظيفة الأمر:** إنشاء مجلد جديد

 ```bash
# إنشاء مجلد باسم Module1
mkdir Module1

 ```

 
### 2. `whoami`

 ```bash
whoami
 ```


**وظيفة الأمر:** الانتقال إلى المجلد السابق

 ```bash
cd ..

 ```


 
 
### 2. ` seq`
**وظيفة الأمر:** إنشاء ملف يحتوي على تسلسل أرقام

 ```bash

seq 1 100 > number.txt
 ```


  
 
### 2. ` cat` & `less`
**وظيفة الأمر:** عرض محتويات الملفات

 ```bash

# عرض محتويات الملف بالكامل
cat number.txt
# عرض محتويات الملف صفحة بصفحة
less number.txt

 ```
   
 
### 2. `rm` & `rm`
**وظيفة الأمر:**  حذف الملفات والمجلدات

 ```bash
# حذف ملف واحد
rm file.txt
# حذف مجلد بكافة محتوياته
rm -r Module1

 ```

 ### 2. `cp` & `mv`
**وظيفة الأمر:**  نسخ أو نقل الملفات

 ```bash
# نسخ ملف إلى مجلد آخر
cp number.txt Module1/
# نقل ملف إلى مجلد آخر
mv number.txt Module1/
# تغيير اسم الملف
mv Textfile.txt version2.txt


 ```


 
 ### 2. `cat >`
**وظيفة الأمر:**  لإنشاء ملف جديد وكتابة محتويات داخله

 ```bash
cat > file.txt
Welcome to Dallah
This is me

#لإنهاء الكتابة اضغط Ctrl+D

 ```

  
### 2. `cat >>`
**وظيفة الأمر:**  لإضافة محتويات إلى ملف موجود

 ```bash
cat >> file.txt

This is course 1


#لإنهاء الكتابة اضغط Ctrl+D

 ```

   
### 2. `cat -n`
**وظيفة الأمر:**  لقراءة الملف مع أرقام الأسطر

 ```bash
cat -n file.txt

 ```

 ### 2. `head` & `tail`
**وظيفة الأمر:**  عرض أول أو آخر عدد معين من الأسطر

 ```bash
# عرض أول أسطر من الملف

 head number.txt
# عرض أول 5 أسطر من الملف
head -n 5 number.txt

# عرض آخر أسطر من الملف
tail number.txt

# عرض آخر 5 أسطر من الملف
tail -n 5 number.txt

 ```


   
### 2. `nano`
**وظيفة الأمر:**  تحرير الملفات النصية

 ```bash
nano course1.txt

Welcome to the course.
We are here to help!

#اضغط Ctrl+X للخروج من الملف

 ```

    
### 2. `echo`
**وظيفة الأمر:**  طباعة النصوص أو حفظها في ملف

 ```bash
# طباعة النص على الشاشة
echo "Hi"
# حفظ النص في ملف جديد
echo "Hi" > info.txt

 ```

 
    
### 2. `grep`
**وظيفة الأمر:**  البحث عن نص معين في ملف

 ```bash
# البحث عن كلمة "me" في الملف info.txt
grep "me" info.txt  # لن يُظهر شيئًا لأن النص غير موجود
# البحث عن نفس الكلمة في file.txt
grep "me" file.txt  # سيُظهر الأسطر التي تحتوي على النص

 ```

     
### 2. `find`
**وظيفة الأمر:**   البحث عن ملفات أو مجلدات

 ```bash
# البحث عن ملف باسم subdir2 في المجلد الحالي
find . -name subdir2
# البحث عن الملفات الفارغة
find . -empty
# حذف الملفات الفارغة
find . -empty -delete
# البحث عن جميع الملفات التي تبدأ بـ subdir
find . -name "subdir*"

 ```

 ### 2. `tar`
**وظيفة الأمر:**  
ضغط وفك ضغط الملفات

 ```bash
# ضغط ملف course1.txt
tar -czvf coursecompress.tar.gz course1.txt
# عرض محتويات الملف المضغوط
tar -tzvf coursecompress.tar.gz
# فك ضغط الملف
tar -xzvf coursecompress.tar.gz

 ```
